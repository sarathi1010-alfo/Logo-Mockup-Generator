# THE ETERNAL WEEKLY RHYTHM

To achieve massive semantic surface area, MockBrand follows a strict production cadence.

## PRODUCTION TARGETS (PER WEEK)
- **Weekly Pillar:** 1 high-authority guide (3,000+ words).
- **Mockup Type Deep-Dives:** 2–3 specific asset guides (Template E).
- **Industry/Use-Case Guides:** 2–3 niche-specific guides (Template F).
- **Competitor Comparisons:** 1–2 "vs" pages (Template B).
- **Daily Clusters:** 3–5 educational articles (Template A).
- **Daily Programmatic:** 5–10 automated template pages.
- **Daily Micro-Answers:** 5 snippet-targeted answers (Template C).

## INDEXING TARGETS
- **Goal:** 50–100 new high-quality pages indexed per week.
- **Verification:** Weekly GSC "Page Indexing" report audit.
- **Action:** Manual indexing request for top-tier Pillar and Deep-Dive pages.

## QUALITY STANDARDS
- **Zero Errors Policy:** Every new URL must be verified for HTTP 200 and schema validity.
- **AEO First:** Every page must contain a 30-50 word direct answer in the first 20% of the content.
- **Interlinking:** Every new page must link to at least 1 Pillar and the core Mockup Generator tool.
